# AI Generated & Testing Tools Archive

This directory stores historical AI-generated scraping tools, temporary testing scripts, data dumps, and screenshot verifications used during the design and optimization of Arun B's academic portfolio website.

## Directory Structure:
- `scripts/`: 53 Python automation, audit, and verification scripts.
- `scraped_data/`: Scraped JSON dumps and raw text extracted from the legacy Google Site.
- `site_mirror/`: Offline mirror snapshot of the legacy Google Site pages.
- `screenshots/`: Rendered visual verification screenshots captured during testing.

These files are archived for historical reference and are **not** needed to serve or deploy the live portfolio website.
